# World War Radio integrated patch, test 1

These replacement sources integrate Landomatic’s Speaker Fix, First Track Fix and Expanded Radio Messages [Audio] compatibility into World War Radio by MaGlas. UBE is optional. The ERM-A timer adjustment activates when the supported timer hook is present.

## Applying to World War Radio

Merge the included Source folder into a copy of World War Radio and replace matching files. Copy CREDITS.txt and LICENSE-Landomatic.txt alongside the original manifest. UBOAT compiles the source. The ZIP includes a compiled private-test DLL for reference. Keep MaGlas’s manifest for his public item and use a separate Workshop identity for private testing. Enable only one WWR build and disable the three standalone fixes when testing this integration.
