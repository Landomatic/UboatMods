Nose Down Depth Companion 1.0.20 -- experimental controls and session status
Prepared 2026-10-17 UTC

CHANGE
Three new opt-in controls: bounded VII entry-pitch torque assistance, a
nonhistorical II/VII precise PD-arrival attempt (ordinary 2-10 m orders),
and pre-dive planes-station availability. All default OFF; existing saved
settings remain. Every hosted Kugler menu now separates session patch
registration from saved selections, with restart-pending indication.
Seakeeping also reports its runtime master separately from the saved master.
The requested GitHub repository and project references are inside LICENSE;
existing terms, copyright and credits are unchanged.

COMPILE
Full source compiles with C# 7.3 against 184 supplied game/Unity/Harmony
assembly references. Compilation does not exercise Unity native behavior.
No game assemblies, upstream sources, personal configs or raw logs ship.

OFFLINE
1125 assertions pass, using actual current selected companion classes,
all three supplied upstream config parsers, the supplied stock torque law,
and Community Patch 0.38.1 row/reset contract code. Game/Unity objects and
Harmony dispatch are fixtures in the host's .NET runtime.
 - All 31 upstream feature switches round-trip ON/OFF through the supplied
   parsers, preserving numeric values, comments, aliases and unrelated files.
 - All three menus report no session patches despite saved config/loaded
   fixture assemblies; informational row setters cannot activate mods.
 - Status getters ignore persisted host values. Seakeeping's saved OFF and

 - Prior casing live update, config-instance replacement, save-failure

 - The three new settings save, reload and reset with defaults OFF.

GAME STATUS AND LIMITS
Not run inside UBOAT. Native Harmony ordering/dispatch, menu rendering,
officer UI/pathfinding/schedules and actual diving response remain unverified.
The preceding 1.0.19 run confirmed entry pitch loss and prolonged PD cycling
with Seakeeping absent and officer PD brake OFF. It did not validate these
new controls. No issue is closed by offline checks.
The arrival attempt applies only where the existing II/VII shallow plane/trim
handover is enabled; Type II additionally requires a seated officer. Other
hulls and depths retain existing controls. The new controller takes precedence
over legacy II/VII arrival/hold offsets and deeper-PD bias while selected.
The game's other depth corrections and environmental forces remain active.

Historical arrival overshoot must not automatically be classified as a fault:
section 106 describes a deliberate overshoot and two air-clearing pitch cycles
for a test dive. This optional precise-arrival mode does not reproduce it.
OFF retains existing behavior; it does not establish historical fidelity.
