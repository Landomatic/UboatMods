LIMITS
No in-game run, UI rendering, campaign serialization, time-compression physics
or measured diving improvement is claimed. The bundled game Harmony library
crashed in this host's .NET 8 runtime during a separate smoke check; native
patch dispatch/order is NOT validated here. Offline tests call callbacks with
fixtures. UBOAT uses its own Unity runtime; this host failure establishes
neither an in-game success nor an in-game failure.

Protected-mode detection uses the existing bridge. Fixtures verify that the
new controls respect its reported protection. Compilation/inspection confirm
reflected members exist in the supplied versions. Future updates can change
these contracts.

Wave reduction cannot guarantee immersion: visible troughs, depth readout,
buoyancy and existing motion are separate effects. Bias trades immersion for
periscope exposure and adds to existing settled-depth error. Try controls
one at a time; the README gives a short initial in-game check.
