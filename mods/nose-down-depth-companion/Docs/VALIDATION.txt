CHANGE
The companion now hosts separate Nose Down, Proper Ballast and Seakeeping
entries with all 31 boolean config switches present in the supplied source
versions: Nose Down 2.1.4 (6), Proper Ballast 1.1.0 (15), Seakeeping 1.2.2 (10).
Numeric controls and retired/bookkeeping fields are excluded. Optional probe
keys are exposed with an explanation that their upstream probe must exist.
Upstream source/manifests/licenses are neither edited nor redistributed.

APPLY BEHAVIOR
All selections save immediately in the corresponding upstream config file.
Only Proper Ballast's casing correction is applied live when a compatible
runtime config is available. Other upstream rows are labelled (restart) and
leave runtime objects alone until the next launch. This avoids pretending to
reverse cached world/UI state. Saved checkboxes can therefore be pending.
The companion's own officer brake remains live, with immediate offset release.
Existing configs can be edited while a mod is disabled, without loading it.

COMPILE

Harmony assembly references. No game assemblies are redistributed.
