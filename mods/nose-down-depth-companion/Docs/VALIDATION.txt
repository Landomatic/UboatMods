Nose Down Depth Companion 1.0.18 -- menu-control validation, 2026-10-17 UTC

CHANGE
Exposes the existing officerPdBrake setting in the companion's menu. Adds a
separate "Kugler diving mods" entry, hosted by this companion, for Proper
Ballast's existing FixCasingFlooding flag. Neither physics algorithm nor its
factory default was changed. The officer switch releases its active offset.

only its matching config key; source, manifest and license stay untouched.

LIMITS AND CURRENT GAME STATUS

unverified. Both flags are read at runtime by the existing control paths, so
switch changes need no restart after the one-time mod installation restart.
Changing the casing option does not rewind water state already produced.
Use the same starting save for A/B comparisons.
The observed 1.0.17 dive-entry level-off, PD overshoot and sustained depth
oscillation remain unresolved. This update provides controls for isolation;
it does not claim to fix or identify those gameplay causes.
The original 1.0.17 physics changes remain experimental; recorded historical
validation and source are retained separately in repository history.
