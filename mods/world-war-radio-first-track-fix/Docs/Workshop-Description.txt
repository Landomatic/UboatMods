An independent companion by Landomatic for World War Radio by MaGlas.

When you tune into a station, the first track should start partway through,
like a live broadcast. World War Radio could apply that random start to the
second track instead. First Track Fix applies the offset to the first track
and lets later tracks start at the beginning.

Requires World War Radio. Enable First Track Fix after it and use your
existing World War Radio career.
