Version 1.4.1

- Added optional Dusty Other Mods controls for Info/Debug/Trace logging and Trace
  interval. Settings apply live and persist; reset restores Info/two seconds.
- Removed the correction switch from the 1.4.0 publishing candidate. The launcher
  controls whether the mod runs; old Enabled/FixEnabled settings are ignored.
- Standardized version numbering and retained lifecycle/station diagnostics,
  throttled Trace sampling, error suppression and cleanup improvements.
- Preserved the submerged/station ownership guards, core repair, Workshop identity
  and license. No camera/FOV or detection-range changes.

Existing diagnostic preferences are kept; use Info for normal play.
