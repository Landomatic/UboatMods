Companion patch for MaGlas's World War Radio on UBOAT 2026.1.

Fixes persistent radio static after loading another save or switching boats. The patch rebinds World War Radio to the current boat and starts new static loops silently. Normal weak-signal static still works.

Requires World War Radio (Workshop ID 3342143865). Enable both mods. Use your existing World War Radio career. Multiplayer compatibility is unverified.

Source and install ZIP: https://github.com/Landomatic/UboatMods
