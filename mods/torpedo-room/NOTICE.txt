GAMEPLAY SCOPE
AZ/MZ follows the game's selectable operating modes. Dry-tube preparation and its
30-game-second default are optional gameplay approximations, not claims that
all historical pistol models could be adjusted instantly in a flooded tube.
Straight running is a gameplay program bypass, not a historical chassis pin.
FAT/LUT has no added failure mechanic or preparation delay. Quarter-metre depth
steps are a requested convention, not a universal historical claim.
No user config migration is performed. Existing license terms remain unchanged.

MP FEUER DISPLAY ADAPTER
An independently authored, opt-in UI adapter targets the supplied MP 1.11.5
station callbacks. MP attribution and license links above remain unchanged.
No upstream source or game assets are copied into this package. This option
permits a masked native Feuer-only panel under MP's scope-panel restriction;
it does not remove MP station access checks, replace host fire dispatch or
change physical TDC/tube lever code. Native confirmation/readiness remains.
