Prepare torpedoes from the torpedo room while keeping the physical flooding,
draining and firing levers. Designed for first-person play, multiplayer station
restrictions, and configurable casual or more demanding play.

FEATURES
- Per-tube depth, supported torpedo speed, AZ/MZ pistol mode and FAT/LUT programming.
- Full-circle LUT heading dial; depth in 0.25 m steps from 0.5 to 14 m.
- Larger room instruments and tube graphics; a prominent Apply button confirms edits.
- Choose current-compartment tubes, read-only opposite tubes, or all editable tubes.
- Synchronized viewing-station controls, read-only reports or hidden reports.
- Independent host toggle for bidirectional TDC speed, preserving target-speed estimates.
- Follow the game knots / km/h preference in room speed controls.
- Torpedo icon hover: model/type, plus maintenance benefit when HTT is installed.
- No scope checkmarks required for the last explicitly applied room speed focus.
- Configurable pistol preparation policies, including timed dry-tube preparation.
- Optional straight-running mode for programmable torpedoes; no added failure rate.
- Existing multiplayer station, role and firing permissions continue to apply.

USE
At a tube station press T (configurable). Choose a tube, edit its preparation,
then click Apply. Physical controls continue to flood, drain and fire.
With bidirectional speed sync ON, the TDC follows consistently selected torpedoes
and its speed dial updates their supported speed presets. Without checkmarks, Apply
on a speed-prepared room tube sets the focus. Turn this independent option OFF to
prepare tube speeds and the TDC separately. Report visibility does not control it.
Mixed speeds and TDC mismatches are warnings only; existing native readiness and
multiplayer firing permissions determine whether a station may fire.

CONFIGURATION
Optional Dusty's Community Patch integration provides the settings menu.
Standalone configuration: TorpedoRoomConfig.txt under UBOAT's persistent-data
folder (Windows: AppData/LocalLow/Deep Water Studio/UBOAT).
Default room shortcut: T. No settings migration is performed.

COMPATIBILITY
Single player; optional Uboats: Coop Multiplayer 1.11.5 / protocol 54.
All shared-boat players need the SAME Torpedo Room version (0.1.18 uses TRC7).
Multiplayer and Dusty's Community Patch are not bundled or required for solo use.
Uses live native artwork and can retain installed Torpedo Type Icons colors.
Compatibility with every mod stack is not established. Larger-stack loading/crash
interactions are being investigated separately. Hover information is deliberately minimal: type/model plus maintenance benefit
when Happy Torpedo Time is present. Full native/HTT tooltip contents are not copied.
